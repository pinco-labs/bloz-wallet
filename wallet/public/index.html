Un laboratorio locale per creare e recuperare un wallet BLOZ SegWit. Le chiavi vengono elaborate sul tuo dispositivo.

Solo test, nessun fondo reale. Ricezione e invio sulla sola regtest locale isolata. Firma sul dispositivo.

Non custodial: il wallet è sotto il tuo controllo

Pinco Labs non custodisce i tuoi fondi. Chiavi private e password del backup vengono elaborate sul tuo dispositivo e non sono inviate a Pinco Labs o ai nodi. La firma delle transazioni avviene nel browser; ai nodi vengono inviate solo le richieste pubbliche necessarie e le transazioni già firmate.

Nella modalità Electrum, le connessioni ai server sono cifrate tramite WSS. In alternativa, nella copia locale puoi usare il tuo nodo BLOZ Core tramite il collegamento RPC locale. I nodi Pinco Labs sono facoltativi.

Non possiamo recuperare la tua password o sostituire un backup perso. Conserva il file cifrato e la sua password: servono entrambi per il recupero.

Vuoi avviarlo sul tuo PC? Guida semplice

Per l’uso abituale consigliamo la copia locale, possibilmente collegata al tuo nodo BLOZ Core via RPC oppure a server Electrum gestiti da te. Puoi scegliere quando aggiornare il codice e a quali nodi affidare le letture della blockchain. La versione web resta una soluzione comoda quando ne hai bisogno; in entrambe le modalità chiavi e firma restano nel browser. Scarica i sorgenti ufficiali su GitHub e segui questi passaggi.

  1. Installa Node.js 24 LTS. Scarica da GitHub la versione indicata da Pinco Labs ed estrai lo ZIP.
  2. Apri un terminale nella cartella estratta che contiene la sottocartella wallet.
  3. Esegui npm ci --prefix wallet per installare le dipendenze della versione scaricata.
  4. Esegui npm run build:electrum --prefix wallet, poi npm run electrum --prefix wallet.
  5. Lascia aperto il terminale e apri http://127.0.0.1:8091/ nel browser. Per fermare il servizio premi Ctrl+C nel terminale.

In locale non significa offline: saldo e invio richiedono i nodi Electrum oppure il tuo nodo BLOZ configurato. Il wallet sul sito e quello locale hanno archivi separati nel browser: per passare da uno all’altro usa il backup cifrato. Non aprire index.html con un doppio clic.

La custodia locale non protegge da malware o estensioni invasive. Mantieni aggiornati sistema e browser e verifica la provenienza del codice che esegui.

02

METTI AL SICURO IL RECUPERO

Scarica il backup cifrato

Scegli una password lunga e unica, di almeno 12 caratteri: una frase composta da più parole casuali e non collegate può essere facile da ricordare senza essere facile da indovinare. Evita citazioni famose, dati personali e password già usate altrove.

Conserva almeno due copie del backup JSON cifrato su supporti diversi, per esempio una in una cartella del PC e una su una chiavetta USB. Custodiscile in luoghi fisicamente separati, così un furto, incendio o guasto non coinvolga entrambe. Aggiungi una copia del solo file cifrato su un servizio cloud, proteggendo l’account con l’autenticazione a due fattori.

La copia nel browser è una comodità e può essere cancellata: non sostituisce i backup esterni. Conserva la password al sicuro, separata dai file, senza affidarti soltanto alla memoria. Per recuperare servono sia il file sia la password; non possiamo reimpostarla. Verifica periodicamente che le copie siano leggibili: più copie riducono il rischio di perdita, senza garantire il recupero in ogni situazione.

Cambia password

Crei un nuovo file cifrato dello stesso wallet: indirizzo e fondi non cambiano. Prima scarichi e verifichi il nuovo file, poi confermi il cambio della password in questo browser.

I vecchi file restano validi con la vecchia password. Il cambio non li aggiorna e non li revoca. Se qualcuno ha già il vecchio file e la sua password, può ancora accedere al wallet: in quel caso occorre un nuovo wallet e trasferire i fondi.

Conserva le copie in cartelle riconoscibili e registra quale password appartiene a ciascun backup, tenendo la password separata dal file. Non cancellare le vecchie copie prima di avere verificato quelle nuove.

    I nodi Pinco Labs sono una scelta predefinita, non un obbligo. Nella tua copia locale puoi configurare altri server Electrum compatibili con BLOZ, anche gestiti da te, oppure usare il tuo nodo BLOZ Core tramite il collegamento RPC locale.

    Questa versione richiede due endpoint Electrum WSS distinti per il confronto delle risposte. Abbiamo collaudato i due server Pinco Labs; la compatibilità con installazioni di terzi non è ancora stata collaudata. Il menu mostra i profili configurati, non un elenco di tutti i nodi disponibili.

    La connessione serve a leggere la blockchain e trasmettere transazioni già firmate. Cambiarla non cambia chiavi, indirizzo o backup. Scegli soltanto server di cui ti fidi.

    Il gestore del nodo scelto può vedere l’IP della connessione e le richieste pubbliche del wallet. Le sue regole di conservazione dei dati possono differire da quelle di Pinco Labs. Chiavi private e password del backup restano sul dispositivo.

    Come viene protetto il backup

    Il file protegge la chiave privata con la tua password. Cifratura e apertura avvengono sul tuo dispositivo: la password non viene inserita nel file né inviata ai nodi.

    Usiamo AES-256-GCM, che cifra i dati e ne verifica l’integrità. La chiave di cifratura viene derivata dalla password con PBKDF2-HMAC-SHA-256, con 600.000 iterazioni per rallentare i tentativi di indovinarla.

    Ogni nuova cifratura genera un salt casuale di 128 bit e un IV casuale di 96 bit tramite il generatore crittografico del browser. Il tag di autenticazione è di 128 bit. Anche i parametri di formato e rete sono autenticati. Scaricare un’altra copia dello stesso backup conserva invece lo stesso file cifrato.

    Il JSON contiene in chiaro i parametri tecnici necessari per aprirlo, ma chiave privata e indirizzo sono cifrati. La robustezza della password resta essenziale: scegli una password lunga e unica, per esempio composta da più parole casuali. Il minimo di 12 caratteri non garantisce da solo una password forte. La cifratura del file non protegge da un dispositivo compromesso mentre il wallet è aperto.

    Blocco dopo 5 minuti di inattività e quando nascondi la pagina. Prima dell’attivazione, una sessione bloccata va ripristinata dal file già scaricato.

    Privacy e dati nel browser

    Il browser conserva una copia cifrata del wallet e la connessione scelta, fino alla loro rimozione o alla cancellazione dei dati del sito. Conserva un backup esterno verificato prima di cancellarli. Non usiamo strumenti pubblicitari o di profilazione; Cloudflare può usare strumenti tecnici per proteggere il sito.

    I nodi scelti possono associare l’IP alle richieste pubbliche del wallet. I nodi Pinco Labs sono facoltativi: la copia locale permette profili Electrum BLOZ personalizzati o il collegamento RPC al proprio Core. Chiavi private e password non vengono inviate ai nodi.

I nuovi log applicativi dei nostri nodi conservano avvisi ed errori per circa 24 ore con rotazione oraria; i log di sistema e precedenti seguono politiche separate. Non garantiamo anonimato completo.
